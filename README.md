# Aribot for Cursor

[Aribot](https://aribot.ayurak.com) by Ayurak, as a Cursor plugin: threat models, cloud compliance posture,
code-security and shadow-AI findings, framework coverage and governed remediation for your own Aribot workspace.

The plugin connects to the Aribot remote MCP server at `https://mcp.aribot.ayurak.com/mcp` and signs you in
with OAuth (your Aribot account). Every call is scoped to your company.
